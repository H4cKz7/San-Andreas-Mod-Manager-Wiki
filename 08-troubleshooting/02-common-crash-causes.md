### Game crashes randomly and doesn't leave a crash log.

Possible reasons for this kind of crash:
- You might be hitting your game's memory limit. Make sure you have essentials pack installed from mixmods and on top install the [Proper Streaming](https://www.mixmods.com.br/2026/10/proper-streaming/) mod to prevent 99% of these issues.
- A faulty CLEO script. It can be debugged using the [SCRLog](https://www.mixmods.com.br/2020/10/iii-vc-sa-scrlog-2020-3-descobrir-crash-em-mod-cleo/) mod.
