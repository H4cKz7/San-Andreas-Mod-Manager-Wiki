A profile is a named set of enabled mods. **Make current** writes `Profile = <name>` into `modloader.ini`.

## Create a profile

Open the three-dot menu next to the profile drop-down and choose **New profile…**.

## Parents

A profile can inherit from parents. See [[Installing a mod]] for how new mods are enabled in the current profile.
